# 구글 로그인 켜는 방법 (사장님용 · 그림 없이 글로만)

> **소요 시간: 약 7분**
> 이메일 로그인은 이미 잘 됩니다. 이 문서는 **구글 로그인만** 켜는 방법입니다.
> 구글 로그인이 굳이 필요 없으시면 **이 문서는 안 하셔도 됩니다.**

---

## 먼저 알아두실 것 (중요)

제가 지금 프로젝트 안의 파일을 다시 확인해 보니, 제가 이전에 드린 안내가 **한 군데 틀렸습니다.**

| 제가 이전에 말한 것 | 실제 상황 |
|---|---|
| "`com.flownote.app` 앱 카드를 찾아서 지문 추가" | ❌ **그 앱 카드는 콘솔에 아예 없습니다** |

**왜 그런가:**
Firebase 콘솔에는 옛날 앱 `com.florascan.scan` **하나만** 등록되어 있습니다.
지금 앱 이름은 `com.flownote.app` 으로 바뀌었는데, 콘솔에는 등록이 안 된 상태입니다.
제가 예전에 APK 빌드를 통과시키려고 `google-services.json` 파일에 `com.flownote.app` 줄을
**손으로 복사해 넣었습니다.** 그래서 빌드는 되지만 구글 로그인은 안 되는 겁니다.

**그래서 사장님이 하실 일은 "지문 추가"가 아니라 "앱 새로 등록"입니다.**
(앱을 등록하는 과정 안에서 지문도 같이 넣게 됩니다)

> 걱정 안 하셔도 되는 점: 앱을 새로 등록해도 **기존 데이터는 하나도 안 지워집니다.**
> 이미 가입하신 계정, 저장된 영수증 전부 그대로 유지됩니다.
> `com.florascan.scan` 옛날 앱도 **지우지 마시고 그냥 두세요.**

---

## 준비물 — 이 두 줄을 복사해 두세요

**SHA-1** (이거 하나만 있으면 구글 로그인 됩니다)
```
796c012932f0aafb3f1dce2956739477988ef612
```

**SHA-256** (있으면 좋음, 나중에 필요할 수 있음)
```
a1f199f3350889b274a170a703453b7084273b0391ff2e485c2b8cc8e81098dc
```

**패키지 이름** (오타 나면 절대 안 됩니다, 그대로 복사)
```
com.flownote.app
```

---

## STEP 1 — 구글 공급업체 켜기 (2분)

1. 브라우저에서 아래 주소를 엽니다
   ```
   https://console.firebase.google.com/project/flownote-404ef/authentication/providers
   ```
2. 화면에 **공급업체(Sign-in providers)** 목록이 나옵니다
3. **`Google`** 을 찾아서 클릭
   - 목록에 안 보이면 **[새 공급업체 추가]** 버튼 → `Google` 선택
4. 오른쪽 위 **사용 설정(Enable)** 토글을 **켭니다** (파란색이 되게)
5. **프로젝트 지원 이메일** 칸이 비어 있으면 → 드롭다운 눌러서 **사장님 이메일 선택** (필수입니다)
6. **[저장]** 클릭

여기까지 하면 서버 쪽은 준비 완료입니다.

---

## STEP 2 — 앱 새로 등록하기 (3분) 🔴 핵심

1. 브라우저에서 아래 주소를 엽니다
   ```
   https://console.firebase.google.com/project/flownote-404ef/settings/general
   ```
2. 화면을 **아래로 스크롤**하면 **내 앱(Your apps)** 이라는 칸이 있습니다
3. 거기에 **`com.florascan.scan`** 이라는 앱이 보일 겁니다
   - ⚠️ **이건 옛날 앱입니다. 절대 지우지 마세요. 그냥 두세요.**
4. **[앱 추가]** 버튼을 누릅니다
   - 안 보이면 앱 목록 아래쪽의 **`+`** 아이콘 또는 **[앱 추가]** 텍스트를 찾으세요
5. 플랫폼 선택 창이 뜨면 **안드로이드 아이콘 (로봇 모양)** 을 클릭
6. 입력 화면이 나옵니다. 아래처럼 채웁니다

   | 칸 이름 | 넣을 값 |
   |---|---|
   | **Android 패키지 이름** (필수) | `com.flownote.app` ← 그대로 복사 |
   | 앱 닉네임 (선택) | `FlowNote` (아무거나 됩니다) |
   | **디버그 서명 인증서 SHA-1** (선택이라 써있지만 🔴 **꼭 넣으세요**) | `796c012932f0aafb3f1dce2956739477988ef612` |

   > "디버그 서명"이라고 써있어서 헷갈리실 텐데, **여기에 넣으면 됩니다.** 상관없습니다.

7. **[앱 등록]** 버튼 클릭

---

## STEP 3 — google-services.json 파일 받기 (1분) 🔴 핵심

앱 등록을 누르면 **바로 다음 화면**에 나옵니다.

1. **[google-services.json 다운로드]** 버튼 클릭
   - 보통 컴퓨터의 `다운로드` 폴더에 저장됩니다
2. 그 다음 화면들은 **[다음]** → **[다음]** → **[콘솔로 이동]** 을 눌러서 그냥 넘어가세요
   - Gradle 코드 붙여넣으라는 안내가 나오는데 **그건 제가 이미 다 해놨습니다. 무시하세요.**

### 파일 잘 받았는지 확인하는 방법 (선택)

받은 `google-services.json` 파일을 메모장으로 열어보세요.
`oauth_client` 이라는 글자를 찾아서, 그 뒤가 이렇게 **채워져 있으면 성공**입니다.

```json
"oauth_client": [
  {
    "client_id": "250664220370-무언가긴글자.apps.googleusercontent.com",
    "client_type": 1,
    "android_info": {
      "package_name": "com.flownote.app",
      "certificate_hash": "796c012932f0aafb3f1dce2956739477988ef612"
    }
  },
  ...
]
```

이렇게 **비어 있으면 실패**입니다. STEP 2 의 SHA-1 입력을 다시 확인하세요.
```json
"oauth_client": []
```

---

## STEP 4 — 저에게 파일 주시기

받으신 `google-services.json` 파일을 **이 채팅창에 그냥 끌어다 놓거나 첨부**해 주세요.

제가 받으면 바로 이렇게 처리합니다.
1. 프로젝트의 `android/app/google-services.json` 교체
2. `oauth_client` 채워졌는지 검증
3. APK Build 13 새로 빌드
4. 다운로드 링크 드리기

**설치하시면 구글 로그인 버튼이 실제로 동작합니다.**

---

## 자주 막히는 곳

| 증상 | 원인 | 해결 |
|---|---|---|
| **[앱 추가] 버튼이 안 보인다** | 페이지를 아래로 안 내렸다 | `내 앱` 칸까지 스크롤. 브라우저 창을 최대화하면 잘 보입니다 |
| **"이 패키지 이름은 이미 사용 중"** | 이미 등록되어 있다 | 새로 만들 필요 없음. 그 앱 카드에서 **[디지털 지문 추가]** 로 SHA-1만 넣고 STEP 3 으로 |
| **SHA-1 넣는 칸이 안 보인다** | 앱 등록 첫 화면에서 접혀 있다 | 등록 후에도 넣을 수 있습니다. 앱 카드 → **[디지털 지문 추가]** |
| **다운로드한 json 의 `oauth_client` 가 비어 있다** | SHA-1 이 저장 안 됐다 | 앱 카드에서 SHA-1 이 목록에 보이는지 확인 → 다시 다운로드 |
| **"프로젝트 지원 이메일을 선택하세요"** | STEP 1 의 5번을 건너뜀 | 구글 공급업체 화면에서 이메일 선택 후 저장 |
| **앱에서 구글 로그인 눌렀는데 창이 바로 닫힌다** | 새 json 이 안 들어간 APK 를 쓰고 있다 | 제가 새로 빌드한 Build 13 을 설치해야 합니다 |

---

## 정리 — 딱 4가지만 하시면 됩니다

1. **구글 공급업체 ON** + 지원 이메일 선택 → 저장
2. **앱 추가** → 패키지 `com.flownote.app` + SHA-1 `796c012932f0aafb3f1dce2956739477988ef612`
3. **google-services.json 다운로드**
4. **저에게 파일 전달** → 제가 APK 새로 빌드

> 이메일/비밀번호 로그인은 지금도 잘 됩니다. 구글 로그인 없이 쓰셔도 아무 문제 없습니다.

---

## 참고 — SHA 값은 어디서 나온 건가

APK 에 서명하는 열쇠(`android/release-key.jks`)의 지문입니다.
Firebase 는 "이 지문으로 서명된 앱만 구글 로그인을 허용한다"는 방식으로 보안을 확인합니다.
그래서 콘솔에 이 지문을 미리 알려줘야 합니다.

```
SHA-1   : 79:6C:01:29:32:F0:AA:FB:3F:1D:CE:29:56:73:94:77:98:8E:F6:12
SHA-256 : A1:F1:99:F3:35:08:89:B2:74:A1:70:A7:03:45:3B:70:84:27:3B:03:91:FF:2E:48:5C:2B:8C:C8:E8:10:98:DC
```

콜론(`:`)은 있어도 되고 없어도 됩니다. 대소문자도 상관없습니다.

> ⚠️ 이 열쇠 파일(`release-key.jks`)과 비밀번호는 **절대 잃어버리면 안 됩니다.**
> 잃어버리면 나중에 앱을 업데이트할 수 없게 됩니다.
